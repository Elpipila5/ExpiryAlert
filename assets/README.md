# Recursos compartidos

Guardar aquí prototipos, iconos originales, paleta y recursos comunes. Los recursos que la app carga en ejecución se ubican donde su framework los requiera, dentro de `app/`.

Registrar procedencia y permiso de uso de recursos externos. Usar nombres claros, como `prototipo-inventario-v1.png`. Las capturas de pruebas pertenecen a `docs/evidencias/`.

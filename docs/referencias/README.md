# Documentos de referencia

Este repositorio publica la organización y los requisitos derivados de dos documentos proporcionados por el equipo. Los PDF completos se consultan en los archivos compartidos en la conversación de preparación; no se incluyen copias públicas aquí.

## Actividad 1

Archivo proporcionado: **Actividad_1_Proyecto_App_Caducidad 1 (1).pdf**, cuatro páginas.

Secciones utilizadas: identificación, problemática, objetivos, alcance inicial, delimitación, selección de Scrum y organización del equipo. La numeración F01-F08 corresponde a ese alcance inicial.

## Plan de trabajo

Archivo proporcionado: **Plan de trabajo ExpiryAlert.pdf**, nueve páginas.

Secciones utilizadas: alcance F01-F10, backlog PB01-PB11, nueve sprints, hitos, organización, Definition of Done, riesgos y mecanismo de seguimiento.

Los requisitos operativos del repositorio usan la numeración del plan. La contradicción sobre OCR y las diferencias de código de barras/búsqueda están registradas en [alcance](../alcance.md) y [decisiones](../decisiones.md).

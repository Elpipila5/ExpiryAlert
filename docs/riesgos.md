# Riesgos y contingencias del plan

| ID | Riesgo | Probabilidad / impacto | Respuesta prevista |
| --- | --- | --- | --- |
| R1 | OCR falla por empaque, tipografía o iluminación. | Alta / Alto | Confirmación manual obligatoria, repetición de captura y distintos formatos de prueba. |
| R2 | Restricciones del sistema para acceder a alarmas. | Media / Medio | Hora configurada por el usuario; permisos adicionales opcionales. |
| R3 | Servicio de recetas/YouTube falla o limita consultas. | Media / Medio | Error controlado, caché o enlaces/búsqueda alternativa. |
| R4 | Cantidad estimada se desvía de la real. | Alta / Medio | Verificaciones periódicas, corrección rápida y marcar terminado. |
| R5 | Funciones complejas retrasan el hito S5. | Media / Alto | Priorizar F01-F05, dividir tareas y conservar el flujo principal. |
| R6 | Autenticación, nube, datos y avisos no se integran. | Media / Alto | Integración temprana, ramas cortas y builds frecuentes. |
| R7 | Crecimiento de alcance durante el desarrollo. | Alta / Medio | Registrar cambios, discutir en review y posponer trabajo no esencial. |
| R8 | Un integrante concentra el desarrollo. | Media / Alto | Distribuir historias, revisiones cruzadas y trabajo en pares en tareas complejas. |

Actualizar en cada sprint con incidente observado, responsable de respuesta, issue relacionado y resultado. La existencia de una contingencia no sustituye una prueba de que funciona.

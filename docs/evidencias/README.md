# Evidencias por sprint

Crear carpetas `sprint-01` a `sprint-09` conforme se registren avances reales. Usar [la plantilla](plantilla-sprint.md) para `registro.md`.

- Capturas: `cp04-alta-manual.png`, con caso/fecha y datos ficticios.
- Demos: enlace verificable o video pequeño con flujo explicado.
- Builds: enlace al entregable/release, versión, commit y procedimiento de instalación.
- Pruebas: resultados reales de la matriz, defectos y correcciones.
- Colaboración: issues, pull requests, revisiones y commits de los tres integrantes.

No agregar APK/AAB ni videos grandes al árbol de código. Registrar los enlaces donde se distribuyan. No crear evidencias ni porcentajes de avance ficticios.

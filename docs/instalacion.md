# Instalación y ejecución

**Pendiente de completar con el proyecto existente.** Actualmente este repositorio contiene documentación y estructura de colaboración. No incluye todavía los archivos necesarios para compilar la aplicación.

## Antes de desarrollar

1. Instalar Git y un editor que use el equipo.
2. Clonar el repositorio siguiendo [CONTRIBUTING](../CONTRIBUTING.md).
3. Incorporar el avance inicial en `app/` mediante la tarea T01.
4. Confirmar framework, SDK, plataforma y servicios reales; no instalar herramientas de otra tecnología por una suposición.

## Información que debe agregar T01

| Elemento | Por documentar |
| --- | --- |
| Tecnología y SDK | Nombre y versiones utilizadas. |
| Plataformas | Android/iOS y restricciones reales. |
| Dependencias | Comando de instalación y archivos de bloqueo. |
| Configuración | Archivo de ejemplo, variables necesarias y procedimiento local. |
| Servicios | Autenticación, almacenamiento, nube, OCR y contenido externo existentes. |
| Ejecutar | Comando exacto desde `app/` y dispositivo/emulador necesario. |
| Probar | Comandos reales y pruebas manuales mínimas. |
| Compilar | Comando de build y ubicación del artefacto distribuible. |
| Diagnóstico | Errores frecuentes y soluciones comprobadas. |

La primera integración se valida cuando otro integrante puede reproducir los pasos y ejecutar el proyecto. Los APK/AAB se distribuyen como entregables del sprint o releases cuando existan; no se agregan al árbol de código.
